## 📁 Proyectos

### 🥇 [Bar Management System — El Último Revolcón](./bar-system-proyecto)
> **React · Node.js · Express · MySQL · JWT · BCrypt**

Sistema multisede para gestión de pedidos, inventario y ventas desarrollado en equipo con **metodología Scrum** (7 sprints · 280h). Incluye roles diferenciados (mesero, cajero, administrador), auditoría de acciones, seguridad con JWT y exportación de reportes CSV.

**Estado:** 🔄 Sprint 5/6 — Fase de QA

---

### 🔹 [Sistema Web Clínico — Full Stack](./full-stack-clinica)
> **Java · Spring Boot · Angular · TypeScript · MySQL**

Aplicación full stack para gestión de pacientes, citas médicas y autenticación por roles. Backend con arquitectura MVC en Spring Boot y frontend Angular consumiendo API REST.

---

### 🔹 [Sistema Transaccional — Taller Mecánico](./taller-mecanico-con-trasacciones)
> **SQL Server · T-SQL · Triggers · Stored Procedures · Funciones**

Sistema robusto para gestión de citas, facturación, repuestos y notificaciones. Implementa triggers para integridad de negocio, procedimientos almacenados y auditoría de transacciones.

---

### 🔹 [Pipelines ETL para Datos Masivos](./proceso-ETL)
> **Python · PostgreSQL · Pandas · SQL**

Procesos ETL para extracción, transformación y carga de grandes volúmenes de datos en PostgreSQL. Énfasis en calidad de datos, optimización de consultas y manejo de errores durante la carga.

---

### 🔹 [Sistema de Gestión — Vidriería (CRUD)](./proyecto-vidreria)
> **PHP · MySQL · HTML · CSS · JavaScript**

Sistema de inventario, ventas y pedidos con conexión directa a base de datos MySQL. Incluye módulo de reportes y control de stock en tiempo real.

---

### 🔹 [Blackjack — Estructuras de Datos](./proyecto-de-blackjack)
> **Python · POO · Pilas · Colas · Listas**

Juego de cartas interactivo desarrollado para aplicar estructuras de datos, programación orientada a objetos y control de flujo en Python.
